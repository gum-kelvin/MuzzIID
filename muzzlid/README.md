# MuzzIID — Android client

Flutter Material 3 cattle register with encrypted local enrolment, CameraX guided capture, five-frame bursts, structured vaccination records, English/Luganda, and a bundled ResNet50/ArcFace research embedding model.

Saved offline is in Settings. Export/import, About, haptics, outdoor contrast and district-manifest features have been removed. Identification stays on-device. Research results require manual confirmation and field validation.

With the Nokia connected, unlocked and pointed at a well-lit textured surface:

```sh
./tool/test_android.sh YOUR_DEVICE_ID
```

See [model integration and replacement](../docs/MODEL_INTEGRATION.md), [training provenance](../model_training/README.md), and [Android validation](../docs/ANDROID_VALIDATION.md).
